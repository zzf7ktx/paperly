PAPERLY — OFFLINE PDF EDITOR

1. Extract the entire ZIP file.
2. Double-click "Start Paperly.cmd".
3. Your browser opens Paperly at http://127.0.0.1:4173.
4. Keep the small launcher window open while using the editor.
5. Press Ctrl+C or close that window when finished.

Paperly processes PDFs only on this computer. No internet connection or
installation is required.

SCANNED PDF / OCR

Open the OCR menu in the editor toolbar. Choose "Recognize full page" or
"Select an area". The bundled English OCR model runs locally and converts
recognized lines into editable Paperly text boxes. Red confidence labels mark
text that should be reviewed before export.
